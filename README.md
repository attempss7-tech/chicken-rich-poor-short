# Chicken Short — Why do the rich keep getting richer?

"Why do the rich keep getting richer while the poor get poorer? One chicken explains it."

Remotion 4.0.541 + three.js short (540x960, 30fps, 2280 frames / 75.984s).
Rendered on GitHub Actions in 2 shards (max 2 parallel runners).

- `node scripts/render_range.mjs out/chicken/shardA 0 1139 1.3333`
- `node scripts/render_range.mjs out/chicken/shardB 1140 2279 1.3333`

Frames are 720x1280 JPEG stills; final delivery is 1080x1920 (lanczos upscale) with audio/mix.wav.
